# Alltagshilfe-App

Eigene App für Angebote zur Unterstützung im Alltag (§ 45a SGB XI), getrennt vom Ladenbuch der Textilpflege.

- `prototyp/index.html` – klickbarer Prototyp, nur Testdaten, speichert im Browser. Wird als Artifact veröffentlicht (ohne eigenes `<html>`-Gerüst).
- `prototyp/EUR-Beispiel.pdf`, `prototyp/Rechnung-Beispiel.pdf` – so sehen die Ausdrucke aus.

Inhalte des Prototyps: Einsätze mit Tätigkeiten nach den Landeshinweisen Niedersachsen (Stand 15.10.2025) und Unterschrift,
Klienten mit Entlastungsbetrag (131 €/Monat, Vorjahresrest bis 30.06.), Abrechnung je Pflegekasse mit Leistungsnachweis,
Kassenbuch mit fortlaufender Nummer und Storno statt Löschen, Einnahmenüberschussrechnung als A4-Ausdruck.
